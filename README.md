# Screenplay Studio

Screenplay Studio is a Windows desktop writing app packaged with Electron.

## Repository note

The local folder available on this computer is the packaged Electron app, not the original development source tree. This repository stores the recoverable application bundle files from `resources/app.asar` plus notes for future cleanup.

Not uploaded:

- `Screenplay Studio.exe`
- Electron/Chromium runtime DLLs and `.pak` files
- `node_modules`
- `Screenplay Studio Data` user database and backups

## Local app location

The installed app folder on this machine was:

`E:\app开发\Screenplay Studio`

The user data folder was intentionally excluded:

`E:\app开发\Screenplay Studio Data`
